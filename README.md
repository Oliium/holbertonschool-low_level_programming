# Holbertonschool Low Level Programming

This repository contains all the C programming projects and exercises from the Holbertonschool curriculum. These projects focus on learning the fundamentals of C programming, memory management, and data structures.

## Project Structure

This repository is organized into different folders, each covering a specific topic:

- **hello_world**: First steps with C - printing to the console
- **variables_if_else_while**: Learning about variables, conditionals, and loops
- **functions_nested_loops**: Understanding functions and nested loop structures
- **more_functions_nested_loops**: More advanced function and loop concepts
- **pointers_arrays_strings**: Working with pointers, arrays, and string manipulation
- **recursion**: Understanding and implementing recursive functions
- **malloc_free**: Dynamic memory allocation and deallocation
- **more_malloc_free**: Advanced memory management techniques
- **argc_argv**: Learning how to use command line arguments in programs
- **variadic_functions**: Functions that accept a variable number of arguments
- **singly_linked_lists**: Implementing and working with linked lists
- **structures_typedef**: Creating custom data types with structures
- **function_pointers**: Using functions as variables through pointers
- **intro_debugging**: Introduction to debugging techniques
- **dynamic_analysis**: Tools and methods for dynamic program analysis
- **benchmarking**: Performance measurement and optimization
- **simple-calculator**: A project combining multiple concepts

## Getting Started

Each folder contains multiple C files with different exercises. To compile and run a program:

```bash
gcc -Wall -Werror -Wextra -pedantic filename.c -o output_name
./output_name
```

## Learning Goals

By working through these projects, you will learn:

- How to write and compile C programs
- Variables and data types
- Control flow (if statements, loops)
- Functions and code organization
- Pointers and memory management
- Arrays and strings
- Advanced data structures
- Debugging and testing
- Best coding practices

## Notes

- All code follows the Betty style guide
- Each project includes header files for organization
- Most programs are compiled without errors or warnings
- Programs are tested for memory leaks using valgrind

Good luck with your learning journey!
